# DCubic Image System Platform — Site Institucional

Site de apresentação pública do **DCubic Image System Platform**, plataforma de análise de volumes 3D micro-CT desenvolvida no contexto de pesquisa acadêmica na USP/FOUSP.

## URL de produção (provisória)

**https://dcubic-image-system-platform.abedrdador.workers.dev**

Hospedagem provisória via **Cloudflare Workers** (arquivo estático) até migração para servidor institucional da USP.

## Conteúdo

Página única (`index.html`) com as seguintes seções:

- Hero com identidade visual DCubic
- O que é o DCubic Image System Platform (com nota sobre validação sintética)
- Funcionalidades com 4 capturas reais do app (triplanar, segmentação, render 3D, métricas)
- Princípio 1: integridade de dados (separação dado × exibição)
- Stack tecnológica
- Vínculo institucional USP/FOUSP
- Rodapé com contato abefisio@usp.br

## Sobre o app técnico

O app Streamlit de análise (porta 8503) corre exclusivamente em ambiente local — não há URL pública para o app neste momento. O botão "Acessar o app" mantém placeholder `#` até a disponibilização de um endereço público.

## Pesquisa acadêmica — sem fins comerciais

Desenvolvido para pesquisa odontológica/biomédica na USP/FOUSP. Uso exclusivamente acadêmico.
